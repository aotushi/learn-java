# 综合项目：进销存与订单管理后台

## 项目定位

这是一个独立的企业后台，不是 Magento 的 Java 后端，也不默认连接任何商城。

后期可以使用官方 RuoYi-Vue 作为登录、权限、菜单、日志和后台页面底座，但商品、库存、采购和订单规则需要自己设计与实现。

## 核心模块

### 1. 用户与权限

- 用户、角色、部门和菜单。
- 按钮权限与接口权限。
- 仓库级数据权限。
- 登录日志和操作审计。

### 2. 商品与仓库

- 商品、SKU、单位和状态。
- 多仓库管理。
- 库存余额与不可修改的库存流水。
- 入库、出库、调拨和盘点。

### 3. 供应商与采购

- 供应商档案。
- 采购单及明细。
- 草稿、审核、入库、完成和取消状态。
- 入库后自动增加库存并留下流水。

### 4. 客户与订单

- 客户档案。
- 销售订单及明细。
- 下单、审核、出库、完成和取消状态。
- 出库时安全扣减库存，不能产生负库存。

### 5. 预警与异步任务

- 低库存预警。
- RabbitMQ 异步生成通知任务。
- 消费失败重试与失败记录。
- 重复消息不会重复产生库存变化。

### 6. 查询与报表

- 条件查询、分页和排序。
- 库存流水、采购和销售汇总。
- Excel 导入导出。
- 操作和异常日志查询。

## 技术要求

- Java 25、Maven、Spring Boot。
- MySQL 持久化与明确事务边界。
- Redis 只用于缓存和短期状态，不作为订单唯一存储。
- RabbitMQ 任务具备确认、重试和幂等保护。
- 所有金额使用最小货币单位或 `BigDecimal`。
- 关键规则包含自动测试。
- 所有依赖服务可通过 Docker 启动。

## 推荐交付顺序

1. 商品和仓库查询的最小闭环。
2. 入库并产生库存流水。
3. 销售订单出库和库存扣减。
4. 权限与仓库数据范围。
5. 低库存异步通知。
6. 报表、审计、备份和恢复。

## 完成定义

- 新环境可以按 README 一次启动。
- 关键业务流程可演示且有测试。
- 并发与重复请求不会破坏库存。
- 权限不能只依赖前端隐藏按钮。
- 数据库可以备份并实际恢复。
- 不直接修改 RuoYi 框架核心代码。
- 已知限制和下一步计划有明确记录。
