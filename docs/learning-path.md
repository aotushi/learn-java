# Java → Spring Boot → RuoYi 学习路线

## 总目标

完成后应当能够：

1. 使用现代 Java 清晰表达业务规则，并处理错误和边界情况。
2. 使用 Maven、JUnit 和调试工具维护可重复构建的项目。
3. 使用 MySQL、事务、索引和缓存处理后台业务数据。
4. 使用 Spring Boot 开发、测试和维护 REST API。
5. 理解认证、授权、审计、并发和异步任务。
6. 阅读并扩展 RuoYi，而不是只会运行代码生成器。
7. 独立完成进销存与订单管理后台。

## 建议周期：24 周

每周 6–10 小时。如果同时学习 PHP/Magento，建议 Java 每周安排 2 天，保持稳定节奏，不要两套框架同时冲刺。

### 第 1–2 周：环境与 Java 基础

- Java 编译、运行、JDK、JVM 和字节码的关系。
- 变量、基本类型、字符串、条件、循环、方法、数组和 `record`。
- 金额使用整数最小单位或 `BigDecimal`，不直接使用 `double`。
- 练习：商品小计、折扣、运费和订单总额。

验收：非法价格和数量有明确错误；至少准备 6 个边界案例。

### 第 3–4 周：面向对象、集合与泛型

- 类、对象、封装、接口、组合、继承和不可变对象。
- `List`、`Set`、`Map`、迭代、Stream 和泛型。
- 异常、枚举、日期时间和空值处理。
- 练习：可替换的折扣策略与订单状态。

验收：新增折扣类型不需要修改订单计算核心逻辑。

### 第 5–6 周：Maven、测试与调试

- Maven 生命周期、依赖、插件、目录约定和版本管理。
- JUnit：正常、边界、异常和回归测试。
- 日志、堆栈、断点、最小复现与问题定位。
- Git 分支、提交和代码审查基础。

验收：一个缺陷能稳定复现，修复后有自动测试保护。

### 第 7–8 周：MySQL 与 JDBC

- 表、约束、连接、聚合、事务和隔离级别。
- 索引、`EXPLAIN`、分页、锁和并发更新。
- JDBC、参数绑定、连接池和数据库迁移概念。
- 设计商品、仓库、库存流水、订单和订单行。

验收：订单创建和扣减库存处于同一事务；查询能说明索引依据。

### 第 9–11 周：Spring Boot 与 REST API

- 依赖注入、配置、Controller、Service 和错误处理。
- HTTP 方法、状态码、JSON、输入验证和分页。
- 单元测试、Web 测试和集成测试的边界。
- 使用 `projects/order-admin-api` 逐步增加功能。

验收：API 对正常、缺失、冲突和非法输入返回正确状态与错误信息。

### 第 12–13 周：数据访问与事务

- Spring JDBC、MyBatis 或 JPA 的适用场景。
- 实体、查询、Repository、事务边界和 N+1 问题。
- 乐观锁、悲观锁、幂等和重复提交。

验收：并发扣减库存不会产生负数；失败时所有相关数据一起回滚。

### 第 14–15 周：认证、授权与审计

- 密码散列、登录、Session/JWT 和 Token 生命周期。
- 用户、角色、菜单、按钮和数据权限。
- Spring Security、最小权限和操作审计。

验收：仓库人员只能查看授权仓库，管理员可以追踪关键操作人和时间。

### 第 16–17 周：缓存与消息队列

- Redis 的键、过期、缓存失效和热点数据。
- RabbitMQ 的生产者、消费者、确认、重试和失败处理。
- 业务幂等与最终一致性。

验收：重复消息不会重复扣库存，失败任务可查、可重试。

### 第 18–20 周：RuoYi 阅读与扩展

- 先阅读登录、权限、菜单、日志和代码生成流程。
- 理解多模块 Maven 结构、Spring Security、MyBatis 和数据权限。
- 使用官方 RuoYi-Vue 单体版，暂不进入 RuoYi-Cloud。
- 开发独立业务模块，不修改框架核心逻辑。

验收：能解释一次受权限保护的请求经过哪些关键部分，并独立增加业务模块。

### 第 21–24 周：综合项目

完成 [进销存与订单管理后台](capstone.md)。项目独立运行，不依赖 Magento。

验收：另一位开发者可以仅根据 README 安装、配置、运行测试、演示和恢复数据。

## 学习原则

- 前期自己实现小项目，后期再用 RuoYi，避免被现成功能遮住原理。
- 每个业务规则先用测试表达，再写实现。
- 不为了使用设计模式而增加抽象，只在真实替换点使用接口。
- 遇到问题先复现、收集证据、定位根因，再修复。
- 单体项目学扎实之后再考虑微服务。
