# 阶段 06：数据访问、事务与并发

## 学习内容

- Spring JDBC、MyBatis 与 JPA 的取舍。
- Entity、Repository、DTO 和领域对象的边界。
- 事务传播、回滚规则、锁和并发更新。
- N+1 查询、批量操作和分页。
- Flyway/Liquibase 数据库迁移概念。

## 阶段任务

将 `projects/order-admin-api` 的内存存储替换为 MySQL：

1. 使用迁移文件创建订单表。
2. 创建订单和订单行必须处于同一事务。
3. 数据库唯一约束保护订单号。
4. 并发扣库存不能出现负数。
5. 集成测试使用独立测试数据。

## 验收

能解释事务从哪里开始、哪些异常触发回滚，以及并发冲突如何反馈给调用者。
