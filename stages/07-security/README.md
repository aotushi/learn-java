# 阶段 07：认证、权限与审计

## 学习内容

- 密码散列、登录状态、Session 和 JWT 的取舍。
- 用户、角色、权限和数据范围。
- Spring Security 过滤链与方法权限。
- CSRF、CORS、输入验证和敏感信息。
- 登录日志、操作日志和审计字段。

## 必做练习

1. `ADMIN` 可以管理全部仓库。
2. `WAREHOUSE_STAFF` 只能操作授权仓库。
3. `VIEWER` 只能查询，不能修改。
4. 后端必须校验权限，不能只靠前端隐藏按钮。
5. 库存调整记录操作者、时间和原因。

## 验收

为匿名、无权限、正常权限和跨仓库访问分别编写自动测试。
