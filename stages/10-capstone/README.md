# 阶段 10：综合项目

最终项目是独立的“进销存与订单管理后台”，完整要求见 [综合项目说明](../../docs/capstone.md)。

## 实施节奏

### 第 1 周：最小业务闭环

- 商品、仓库和库存查询。
- 手工入库并产生不可修改的库存流水。
- 基础自动测试。

### 第 2 周：采购与销售

- 采购入库。
- 销售订单和出库。
- 事务、并发和负库存保护。

### 第 3 周：权限与异步任务

- 角色、菜单、按钮和仓库数据权限。
- 低库存 RabbitMQ 通知。
- 重试、幂等和失败记录。

### 第 4 周：交付质量

- 查询、报表和 Excel。
- 日志、监控、备份与恢复。
- Docker 一键启动。
- 演示、安装说明和已知限制。

## 最终验收

请另一位开发者只按 README 操作。如果对方能启动、测试、登录、完成入库与出库、验证权限并恢复数据库，项目才算完成。
